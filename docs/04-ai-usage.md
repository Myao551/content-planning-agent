# AI 辅助范围与验证

## 已发生的辅助

本阶段由 Codex AI 编程助手辅助完成需求分析、技术规划、Python 代码、合成数据、测试、案例执行和交付文档。用户提供了业务资料、选择内容任务规划题目、确认先做离线版本，并指定 GitHub 仓库和提交范围。

离线动作说明和脚本均由本地确定性 Mock 产生；开发过程使用 AI 编程助手，不等于运行中的程序调用了真实模型 API。

## 实际修改与验证

- 根据测试发现修正重试计数：区分全部尝试和连续失败，允许正常的重复估算。
- 核对费用累计、保存前约束、事务回滚、回读、请求重复和资料版本变化。
- 检查额外参数、未知动作、无估算生成、无依据事实和未经保存的完成请求会被拒绝。
- 通过实际 Python 测试、CLI 子进程与案例生成器产出结果，未把预期输出直接写成实际证据。
- 用户试用时指出只能一次运行且 JSON 难读，AI 助手据此增加持续对话、需求增量修改、会话存储、易读结果和步骤进度，并补充相应测试；候选人本人试用与修改仍由本人确认。
- 实际运行一次完整真实对话批次（27 次请求、151297 token），发现模型在自由说明中复述错一个截止月份；改为结构化字段渲染完成摘要，并验证会话恢复与 82 项测试，详见 [评估](03-evaluation.md) 中的观察；开发期逐轮交互目录已按用户要求清理。

实际结果见 [评估](03-evaluation.md)。测试证明所测离线流程与约束，不证明真实模型的业务理解或决策质量。

# 需求与成功标准

## 用户与目标

面向跨境电商运营人员，在给定主题、模拟预算和截止时间内形成可保存的营销视频内容活动方案。第一阶段实现离线业务流程；真实模型决策尚未验证。

输入包括稳定 `request_id`、活动主题、预算和带时区截止时间，可选商品标识、受众、平台和语言。缺预算或截止时间返回 `needs_input`；负预算、非十进制字符串、无时区时间等返回 `invalid_input`。预算 0 是有效输入，不是缺失。

## 范围

- 使用本地合成商品与素材、工具费用与耗时表。
- 四个业务工具：检索素材、生成离线脚本、估算、保存。
- 观察工具结果后调整方案、有限重试、请求信息或停止。
- 保留计划版本、成功/失败步骤、实际模拟费用、产物与保存回执。
- 重复请求回读已有结果，不重复保存或扣费。
- 输出实际记录、工具参数与返回、后续动作及公开的简短说明。

不包含真实模型、视频生成、广告投放、前端、部署、多 Agent、支付、分布式并发或失败跨进程续跑。文档中的语言参数保留为业务偏好，离线脚本不实现翻译。

## 预算与时间

总额是已发生模拟费用、剩余工具费用与最终方案资源预留之和，均以整数千分单位计算。资源预留不是已支付费用，真实 API 请求为 0。

截止时间指方案交付时间。业务时间取实际时钟和累计模拟耗时的较晚者；固定演示时钟仅在显式配置时启用。模拟耗时不等于实际性能。

## 验收点

| 验收点 | 检查 |
| --- | --- |
| 正常完成 | 四工具链路、有效脚本、费用正确、方案可回读 |
| 缺预算或截止时间 | 精确指出缺失项，不启动收费步骤 |
| 工具失败 | 记录失败，保留此前成功产物，有限重试或结束 |
| 预算超限 | 修改方案并重新估算，或明确缺口；不越界收费 |
| 重复执行 | 相同方案 ID，不增加记录、费用或驱动调用 |
| 截止时间 | 选择可行方案或明确未完成，不擅自延长截止时间 |
| 上限及状态 | 超限未完成；没有保存回执不能宣称完成 |

`completed` 仅代表活动方案与脚本保存成功。只有未来真实模型接入并产生不同决策路径的运行证据后，才可进一步评估真实 ReAct 是否达标。

实际检查见 [评估](03-evaluation.md) 和 [案例索引](../examples/README.md)。
